Der Clear-Button (`_hasClearButton`, standardmäßig aktiv) wird angezeigt, sobald das Eingabefeld Text enthält. Er ist als Icon-Button umgesetzt, dessen zugänglicher Name von KoliBri übersetzt bereitgestellt wird (deutsch: „Auswahl entfernen“) und sehenden Nutzenden zusätzlich als Tooltip erscheint. Der Clear-Button ist per Tastatur erreichbar und wird ausgeblendet, wenn die Komponente deaktiviert ist (`_disabled`).
