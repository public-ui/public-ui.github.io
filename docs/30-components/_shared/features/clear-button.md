Mit `_hasClearButton` steuern Sie, ob ein Clear-Button angezeigt wird, über den der aktuelle Wert mit einer einzigen Aktion entfernt werden kann. Der Clear-Button ist standardmäßig aktiv und erscheint, sobald das Eingabefeld Text enthält. Er ist per Tastatur erreichbar und wird ausgeblendet, wenn die Komponente deaktiviert ist (`_disabled`). Sein zugänglicher Name wird von KoliBri übersetzt bereitgestellt (deutsch: „Auswahl entfernen“) und sehenden Nutzenden zusätzlich als Tooltip angezeigt.
