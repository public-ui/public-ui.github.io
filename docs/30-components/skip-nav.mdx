# SkipNav

**Synonyme:** Skip-Link, Skip Navigation, Sprungnavigation, Übersprungung, Navigationssprung

**Beschreibung:** Die **SkipNav**-Komponente erzeugt eine versteckte Navigation, die es Nutzer:innen mit Tastatur und assistiven Technologien ermöglicht, wiederholte Seitenbereiche zu überspringen und direkt zum Hauptinhalt zu navigieren. Sie wird als benannte Navigation (`nav`-Element) mit einer Liste nativer Links (`a`-Elemente) ausgegeben. Ein Link wird erst sichtbar, wenn er den Fokus erhält, z. B. beim Erreichen über die `Tab`-Taste.

**Anwendungsfälle:**
- Längere Websites mit umfangreicher Navigation am Anfang
- Multi-Level-Navigationsstrukturen, die viele Tastaturschritte erfordern
- Seiten mit mehreren Seitenleisten oder wiederholten Inhaltsblöcken
- Blogs oder News-Portale mit vielen Navigations- und Filteroptionen
- Barrierefreie Webanwendungen für verschiedene Nutzergruppen

## Barrierefreiheit

- Die Links sind für Sehende standardmäßig nicht sichtbar. Erhält ein Link den Fokus, wird genau dieser Link eingeblendet; verlässt der Fokus ihn, wird er wieder ausgeblendet.
- Für Screenreader sind die Links jederzeit vorhanden: Sie werden auch ohne Fokus im Lesemodus vorgelesen und erscheinen in der Liste der Links bzw. Landmarks.
- Screenreader kündigen die SkipNav als Navigation mit dem über `_label` gesetzten Namen an, die Links als Liste mit der Anzahl der Einträge. Jeder Link kann direkt angesteuert werden.
- Sie bietet Nutzer:innen mit motorischen Einschränkungen die Möglichkeit, schnell zum Hauptinhalt zu navigieren, ohne wiederholte Navigation durchlaufen zu müssen.

### Konkrete Designentscheidungen

| Entscheidung                                                                       | Begründung                                                                                                                                                                                                    |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `_label` ist ein Pflichtfeld und benennt die Navigation                            | Auf einer Seite kann es mehrere Navigationen geben (z. B. Hauptnavigation, Breadcrumb, Pagination). Damit sie unterscheidbar sind, müssen sie eindeutig benannt sein. Im Entwicklungsmodus gibt KoliBri einen Hinweis in der Konsole aus, wenn das Label fehlt oder bereits von einer anderen Navigation verwendet wird. |
| Hinweis in der Konsole (Entwicklungsmodus) bei mehr als sieben Links               | Innerhalb von Navigationsstrukturen werden höchstens sieben Einträge empfohlen (Millersche Zahl).                                                                                                            |

## Tastatursteuerung

<NativeKeyboardIntro />

| Taste       | Funktion                                                                                                                     |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `Tab`       | Fokussiert den nächsten Link der SkipNav und blendet ihn ein. Steht die SkipNav am Seitenanfang, ist ihr erster Link das erste fokussierbare Element. |
| `Shift+Tab` | Fokussiert den vorherigen Link bzw. das vorherige fokussierbare Element.                                                     |
| `Enter`     | Folgt dem fokussierten Link zum angegebenen Zielanker.                                                                       |

## FAQ

**Wo platziere ich die SkipNav?**  
Platzieren Sie die SkipNav am Anfang der Seite, vor anderen interaktiven Elementen. Nur dann erreichen Tastatur-Nutzer:innen ihren ersten Link mit dem ersten Druck auf die `Tab`-Taste.

**Wie formuliere ich die Link-Beschriftungen?**  
Definieren Sie prägnante und verständliche Link-Labels, die klar beschreiben, wohin der Nutzer navigiert wird (z. B. „Zum Hauptinhalt", „Zur Navigation").

**Wie lege ich die Sprungziele fest?**  
Verwenden Sie semantisch sinnvolle Zielanker als `_href` (z. B. `#main`, `#nav`, `#content`). Die entsprechenden Ziele sollten mit `id`-Attributen versehen sein (z. B. `<main id="main">`).

## Funktionalitäten

### Beschriftung der Navigation

Über `_label` (Pflichtfeld) wird der Name der Navigation gesetzt. Er ist nicht sichtbar, sondern wird von Screenreadern beim Erreichen der Navigation vorgelesen und unterscheidet die SkipNav von anderen Navigationen der Seite.

<SkipNavPreview context="feature" visibleProperties={['_label']} />

### Sprungziele

Die `_links` (Pflichtfeld) werden als Array von Objekten mit `_label` und `_href` übergeben:

```js
[
	{ _label: 'Navigation', _href: '#nav' },
	{ _label: 'Hauptinhalt', _href: '#main' },
	{ _label: 'Kontakt', _href: '#contact' },
];
```

Jeder Link zeigt sein Label an und navigiert zum entsprechenden Zielanker auf der Seite. Die Einträge sind Link-Objekte und übernehmen weitere Properties der <kol-link _label="Link-Komponente" _href="./link" />, z. B. `_target`, `_icons` oder `_ariaDescription`.
