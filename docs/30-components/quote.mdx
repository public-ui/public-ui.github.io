# Quote

**Synonyme:** Zitat, Blockzitat, Textzitat, Quote, Blockquote

**Beschreibung:** Die **Quote**-Komponente präsentiert Zitate mit Quellenangabe. Sie unterstützt zwei Darstellungsvarianten: eine inline-Variante (natives `q`-Element) für kurze Zitate im Fließtext und eine block-Variante (natives `blockquote`-Element) für hervorgehobene, eingerückte Zitate. Die Komponente verbindet das Zitat semantisch mit der Quelle über einen Link.

**Anwendungsfälle:**
- Testimonials: Kundenbewertungen oder Nutzer-Feedback auf Websites oder in Marketing-Material
- Literarische Verweise: Zitate aus Büchern, Artikeln oder Reden in redaktionellen Inhalten
- Forschung: Zitate aus wissenschaftlichen Arbeiten, Studien oder Quellen in akademischen oder informativ-journalistischen Texten
- Autorisierungen: Genehmigungen, Empfehlungen oder Bestätigungen durch Autoritäten oder Experten
- Design-Elemente: Visuelle Highlights in Broschüren, Webseiten oder Präsentationen, um Botschaften zu verstärken

## Barrierefreiheit

- Das Zitat ist als Zitat ausgezeichnet und nicht nur optisch hervorgehoben. Ein Zitat der Variante `block` wird von Screenreadern als eigener Abschnitt angekündigt; der Zitattext wird direkt vorgelesen.
- Die Quelle ist mit dem Zitat verknüpft: Die URL aus `_href` ist am Zitat hinterlegt und bei gesetztem `_label` zusätzlich als sichtbarer, per Tastatur erreichbarer Link in der Quellenangabe verfügbar.
- `_label` ist der Linktext der Quellenangabe und keine Überschrift. Ohne `_label` gibt es weder eine sichtbare Quellenangabe noch einen Link zur Quelle.

### Konkrete Designentscheidungen

| Entscheidung | Begründung |
| ------------ | ---------- |
| Verwendung der nativen Zitat-Elemente `q` (Variante `inline`) und `blockquote` (Variante `block`) | Semantische Zitat-Elemente machen die Art des Inhalts für assistive Technologien erkennbar; die Zitatstruktur muss programmatisch ermittelbar sein (WCAG 1.3.1 Info and Relationships). |

## Tastatursteuerung

Das Zitat selbst ist nicht bedienbar. Per Tastatur erreichbar ist nur der Link zur Quelle, der bei gesetztem `_label` angezeigt wird.

<NativeKeyboardIntro />

| Taste       | Funktion                                                                  |
| ----------- | ------------------------------------------------------------------------- |
| `Tab`       | Fokus auf den Link zur Quelle bzw. das nächste fokussierbare Element setzen. |
| `Shift+Tab` | Fokus auf das vorherige fokussierbare Element setzen.                     |
| `Enter`     | Öffnet die Quelle in einem neuen Tab.                                     |

## FAQ

**Wann sollte ich die Variante `block` und wann `inline` verwenden?**  
Nutzen Sie die Variante `inline` für kurze Zitate im fortlaufenden Text oder in Sätzen. Die Variante `block` ist sinnvoll für längere, eigenständige Zitate, die sich vom Fließtext abheben und visuelle Aufmerksamkeit erhalten sollen. Verwenden Sie sie, wenn das Zitat mindestens ein bis zwei Sätze umfasst. Entscheiden Sie anhand von Länge und Bedeutung des Zitats und wahren Sie die Konsistenz innerhalb des Dokuments.

**Muss ich eine Quelle angeben?**  
Ja. Geben Sie immer eine Quelle (`_href`) an, damit Lesende die Herkunft des Zitats nachvollziehen können. Damit die Quelle auch sichtbar und als Link erreichbar ist, setzen Sie zusätzlich `_label` (siehe [Zitat und Quellenangabe](#zitat-und-quellenangabe)).

**Welches Zitierformat sollte ich für `_label` nutzen?**  
Nutzen Sie `_label` für Autoren-, Werk- oder Kontextangaben, um das Zitat einzuordnen. Das Trennzeichen ist flexibel – gängig sind Formate wie „Autor, Werk“, „Quelle (Datum)“ oder einfach nur „Autorname“. Wichtig ist Konsistenz innerhalb des Dokuments. Da `_label` zugleich der Linktext zur Quelle ist, sollte er die Quelle auch ohne umgebenden Text verständlich benennen.

**Kann ich das Zitat mit HTML oder Markdown formatieren?**  
Das `_quote`-Attribut erwartet reinen Text. Formatierungen sollten über CSS oder zusätzliche strukturelle Elemente außerhalb der Komponente erfolgen.

**Darf ich Zitate kürzen oder sinngemäß wiedergeben?**  
Reproduzieren Sie Zitate exakt und vermeiden Sie Paraphrasing ohne Hinweis.

## Funktionalitäten

### Zitat und Quellenangabe

Der Zitattext wird über `_quote` gesetzt, die URL der Quelle über `_href` (Pflichtfeld). Mit `_label` wird im Anschluss an das Zitat eine Quellenangabe ausgegeben, die zugleich der Link zur Quelle ist. Der Link öffnet die Quelle immer in einem neuen Tab. Darauf weist ein Icon hin, dessen Text „Öffnet in neuem Tab.“ auch von Screenreadern vorgelesen wird.

<QuotePreview context="feature" visibleProperties={['_quote', '_label', '_href']} />

### Varianten

Die Quote-Komponente bietet zwei Darstellungsvarianten:

- `inline`: Kurzes Zitat im Fließtext (Standard)
- `block`: Hervorgehobenes, eingerücktes Zitat

In beiden Varianten werden die Anführungszeichen automatisch ergänzt und gehören daher nicht in `_quote`.
