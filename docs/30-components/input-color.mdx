# InputColor

**Synonyme:** Farbeingabefeld, Farbauswahl, Farbwähler, Color Input, Color Picker

**Beschreibung:** Mit **InputColor** kann eine Farbe über den Farbwähler des Browsers ausgewählt werden. Die Komponente basiert auf dem nativen HTML5-Eingabetyp `color`: Das Farbfeld zeigt die aktuell gewählte Farbe an und öffnet per Klick oder Tastatur den Farbwähler des Browsers bzw. Betriebssystems.

**Anwendungsfälle:**
- Auswahl einer Primär- oder Sekundärfarbe in Konfigurationsoberflächen
- Festlegen von Hintergrund-, Text- oder Akzentfarben
- Anpassung von Design- oder Theme-Einstellungen
- Konfiguration individueller Farbprofile oder Farbschemata
- Farbwahl in Formularen oder Administrationsoberflächen

## Barrierefreiheit

* <LabelNote />
* <ErrorMessageNote />
* Der native Farbwähler weist in Kombination mit Screenreadern bekannte Barrieren auf. So wird das Feld teilweise nicht als Eingabefeld angesagt, und eine Farbauswahl im Dialog ist mit Screenreadern nicht zuverlässig möglich. Da der Dialog vom Browser bzw. Betriebssystem bereitgestellt wird, kann KoliBri dies nicht beeinflussen. Details finden Sie unter <kol-link _href="https://public-ui.github.io/docs/known-issues#kol-input-color" _target="_blank" _label="Bekannte Probleme: kol-input-color"></kol-link>.

### Konkrete Designentscheidungen

| Entscheidung | Begründung |
| ------------ | ---------- |
| Verwendung des nativen HTML5-Eingabetyps `color` | Die Komponente nutzt bewusst den nativen HTML5-Eingabetyp `color` und profitiert dadurch von dessen standardisierter Unterstützung durch Browser und assistive Technologien. |
| Kein eigener Farbwähler und kein zusätzliches Textfeld | Mit dem bis Version 4.3 vorhandenen Textfeld für HEX-Werte war das Farbfeld nicht per Tastatur erreichbar, sodass sich der Farbwähler nicht per Tastatur öffnen ließ. Da HEX-Werte auch im nativen Farbwähler eingegeben werden können, wurde das Textfeld wieder entfernt (siehe <kol-link _href="https://github.com/public-ui/kolibri/issues/10666" _target="_blank" _label="#10666"></kol-link>). Die Farbauswahl erfolgt seitdem ausschließlich über den nativen Dialog des Browsers bzw. Betriebssystems. |
| Übernahme des Browser-Standardwerts | Ist kein `_value` gesetzt, übernimmt die Komponente nach dem Laden den Standardwert des nativen Farbfelds (`#000000`), sodass Anzeige und Wert der Komponente übereinstimmen. |

## Tastatursteuerung

<NativeKeyboardIntro />

| Taste                 | Funktion                                                               |
| --------------------- | ---------------------------------------------------------------------- |
| `Tab`                 | Fokus auf das Farbfeld bzw. das nächste fokussierbare Element setzen.  |
| `Shift+Tab`           | Fokus auf das vorherige fokussierbare Element setzen.                  |
| `Enter` / `Leertaste` | Farbwähler öffnen, wenn das Farbfeld fokussiert ist.                   |
| `Esc`                 | Geöffneten Farbwähler schließen.                                       |

Die Bedienung innerhalb des geöffneten Farbwählers wird vollständig durch den Browser bzw. das Betriebssystem bestimmt.

## FAQ

**Welche Farbwerte unterstützt die Komponente?**  
Der Wert wird im Format `#rrggbb` übergeben und zurückgeliefert. KoliBri übergibt `_value` unverändert an das native Farbfeld. Andere Schreibweisen wie `#fff` oder Farbnamen behandeln Browser unterschiedlich: Je nach Browser werden sie in das Format `#rrggbb` umgewandelt oder durch `#000000` ersetzt. Verwenden Sie daher immer `#rrggbb`. Der native Farbwähler des Browsers kann – abhängig von Browser und Betriebssystem – weitere Eingabemöglichkeiten wie RGB oder HSL anbieten; der Wert der Komponente bleibt davon unberührt.

**Wie kann ich eine Farbe vorbelegen?**  
Über `_value`, siehe [Vorbelegter Farbwert](#vorbelegter-farbwert). Welcher Wert ohne `_value` gilt, steht unter [Konkrete Designentscheidungen](#konkrete-designentscheidungen).

**Gibt es ein Textfeld für die direkte Eingabe von HEX-Werten?**  
Nein. Bis Version 4.3 bestand die Komponente zusätzlich aus einem Textfeld für HEX-Werte. Seit Version 4.4 wird ausschließlich das native Farbfeld verwendet.

**Kann ich die Farbauswahl als Pflichtfeld oder als schreibgeschützt kennzeichnen?**  
Nein, die Komponente unterstützt weder `_required` noch `_readOnly`. Ob eine Farbauswahl verpflichtend ist, muss durch die Anwendung validiert und über `_msg` kommuniziert werden. Beschreiben Sie in der Fehlermeldung verständlich, wie Nutzende den Fehler beheben können.

**Wie beschrifte ich das Farbfeld verständlich?**  
Verwenden Sie eine aussagekräftige Beschriftung (`_label`), damit Nutzende erkennen, wofür die Farbe verwendet wird (z. B. „Primärfarbe“ oder „Hintergrundfarbe“). Verzichten Sie möglichst auf `_hideLabel`, da einige Screenreader die Beschriftung des nativen Farbfelds nicht zuverlässig ausgeben. Nutzen Sie `_hint`, um ergänzende Hinweise bereitzustellen, beispielsweise zur Verwendung der Farbe oder zu Kontrastanforderungen.

**Wann sollte ich InputColor nicht verwenden?**  
Ist nur eine begrenzte Anzahl an Farben zulässig, verwenden Sie stattdessen eine Auswahl vordefinierter Farben, beispielsweise mit <kol-link _href="./select" _label="Select"></kol-link> oder <kol-link _href="./input-radio" _label="InputRadio"></kol-link>. Beschreiben Sie die Farben dabei zusätzlich in Textform (z. B. „Dunkelblau“).

**Warum sieht der Farbwähler je nach Browser unterschiedlich aus?**  
Die Komponente verwendet den nativen Farbwähler des Browsers. Dessen Darstellung, Bedienung und Funktionsumfang werden durch Browser und Betriebssystem bestimmt.

Mit `_value` legen Sie die vorausgewählte Farbe im Format `#rrggbb` fest (z. B. `#d4fcf4`).

	context="feature"
	visibleProperties={['_value']}
	initialProps={{
		_label: 'Akzentfarbe',
		_value: '#ff6b6b',
	}}
/>

### Events

<EventsIntro />

| Event     | Auslöser                              | Value                                  |
| --------- | ------------------------------------- | -------------------------------------- |
| `click`   | Farbfeld wird angeklickt              | -                                      |
| `focus`   | Farbfeld wird fokussiert              | -                                      |
| `blur`    | Farbfeld verliert Fokus               | -                                      |
| `keydown` | Taste wird im Farbfeld gedrückt       | -                                      |
| `input`   | Farbe wird im Farbwähler geändert     | Aktueller Farbwert im Format `#rrggbb` |
| `change`  | Farbauswahl wurde abgeschlossen       | Aktueller Farbwert im Format `#rrggbb` |
