# InputDate


<BetaDocsBanner />

**Synonyme:** Date Picker, Datumsfeld, Datumseingabe, Datumsauswahl, Date Input

**Beschreibung:** Mit der **InputDate**-Komponente können Nutzende Datums- und Zeitwerte erfassen.

Die Komponente basiert auf den nativen HTML5-Eingabetypen `date`, `datetime-local`, `month`, `time` und `week` und übernimmt deren Semantik, Tastatursteuerung sowie Unterstützung durch Browser und assistive Technologien.

Die Eingabe erfolgt direkt im Eingabefeld oder über einen Auswahldialog. Die konkrete Darstellung und Tastaturbedienung ist dabei abhängig vom verwendeten Browser und Betriebssystem.

## Beispiel

Standard-Datumsfeld mit dem Typ `date`. Die Eingabe erfolgt über direkte Zahleneingabe mit Automatisierung oder über die gerätespezifische Auswahlhilfe.

	visibleProperties={[]}

	sourceCodeDetailsCollapsed
/>

## Barrierefreiheit

- Die nativen HTML5-Eingabetypen werden von Browsern und assistiven Technologien standardisiert unterstützt.
- Das Eingabefeld muss mit einer aussagekräftigen Beschriftung (`_label`) versehen werden. Zusätzliche Hinweise können über `_hint`, Fehlermeldungen über `_msg` bereitgestellt werden.
- Darstellung, Bedienung und Funktionsumfang der nativen Auswahldialoge können sich je nach Browser, Betriebssystem und Endgerät unterscheiden.

### Konkrete Designentscheidungen

| Entscheidung | Begründung |
| ----------- | ---------- |
| Verwendung nativer HTML5-Eingabetypen | Die Komponente nutzt bewusst native HTML5-Eingabetypen und profitiert dadurch von deren standardisierter Unterstützung durch Browser und assistive Technologien. |
| Kein eigener Datepicker bzw. Zeitwähler | Die Komponente verzichtet bewusst auf eine eigene Implementierung und nutzt stattdessen die nativen Auswahldialoge des Browsers bzw. Betriebssystems. ## Verwendung

- Verwenden Sie **InputDate** zur Eingabe von Datums- und Zeitwerten in strukturierter Form. Wählen Sie hierfür den zum Anwendungsfall passenden Eingabetyp (`date`, `datetime-local`, `month`, `time` oder `week`).
- Nutzen Sie `_min` und `_max`, um zulässige Werte fachlich einzuschränken. Verwenden Sie `_step` für den Eingabetyp `time`, um zulässige Zeitintervalle festzulegen.
- Ergänzen Sie keine zusätzlichen ARIA-Rollen oder ARIA-Attribute, um das Verhalten nativer HTML5-Eingabetypen zu verändern.

### Tastatursteuerung

Die Tastaturbedienung wird vollständig durch den Browser und das Betriebssystem bestimmt. Daher können sich die unterstützten Tastaturfunktionen und Tastenkombinationen je nach Browser, Betriebssystem und Eingabetyp unterscheiden.

Typischerweise werden folgende Funktionen unterstützt:

| Taste                 | Funktion                 |
| --------------------- | ------------------------ |
| `Tab`                 | Fokus auf das Eingabefeld bzw. das nächste fokussierbare Element setzen. |
| `Shift+Tab`           | Fokus auf das vorherige fokussierbare Element setzen. |
| `Pfeiltasten`         | Innerhalb des Eingabefeldes oder eines geöffneten Auswahldialogs zwischen den verfügbaren Werten navigieren bzw. den Wert ändern. |
| `Enter` / `Leertaste` | Eingabe oder Auswahl bestätigen. |
| `Esc`                 | Geöffneten Auswahldialog schließen.  |

### Best Practices / Empfehlungen

- Verwenden Sie aussagekräftige Beschriftungen (`_label`), damit der erwartete Datums- oder Zeitwert eindeutig erkennbar ist.
- Ergänzen Sie bei Bedarf zusätzliche Hinweise über `_hint`, beispielsweise zu zulässigen Eingaben oder fachlichen Einschränkungen.
- Berücksichtigen Sie, dass sich Darstellung und Bedienung der nativen Auswahldialoge je nach Browser, Betriebssystem und Endgerät unterscheiden können.

### Anwendungsfälle

- Eingabe eines Geburtsdatums in Registrierungs- oder Kontaktformularen
- Auswahl eines Datums für Terminvereinbarungen oder Reservierungen
- Erfassung von Uhrzeiten, beispielsweise für Öffnungs-, Start- oder Endzeiten
- Auswahl eines Monats oder einer Kalenderwoche für Planungs- und Auswertungszeiträume
- Erfassung eines Datums mit Uhrzeit, beispielsweise für Termine oder Ereignisse

### FAQ

**Kann die InputDate mit einem Wert vorbelegt werden?**  
Ja. Über `_value` kann die Komponente mit einem zum gewählten Eingabetyp passenden Wert initialisiert werden.

**Wie kann InputDate geleernt werden?**  
Setzen Sie `_value` auf `null` oder `undefined`, um den aktuellen Wert zu entfernen.

**Warum sieht InputDate je nach Browser unterschiedlich aus?**  
Die Komponente nutzt die nativen HTML5-Eingabetypen des Browsers. Darstellung und Bedienung der Auswahldialoge werden daher vom jeweiligen Browser und Betriebssystem bestimmt und können variieren.

### Funktionalitäten (mit Code)

#### Beschriftung und Hinweistexte

Das Eingabefeld wird mit einer Beschriftung über `_label` versehen. Zusätzliche Informationen können über `_hint` bereitgestellt werden.

<InputDatePreview
	visibleProperties={['_label', '_hint']}
	initialProps={{ _label: 'Geburtsdatum', _hint: 'Bitte geben Sie Ihr Geburtsdatum ein.' }}
/>

#### Eingabetypen

Das Attribut `_type` bestimmt das Format und den Auswahldialog:

<InputDatePreview
	visibleProperties={['_type']}
	initialProps={{ _label: 'Datum', _type: 'date' }}
/>

**Verfügbare Typen:**
- `date`: Vollständiges Datum (Standard)
- `datetime-local`: Datum und Uhrzeit ohne Zeitzone
- `month`: Nur Monat und Jahr
- `time`: Nur Uhrzeit (HH:MM)
- `week`: Kalenderwoche und Jahr

#### Bereichsbeschränkung

Die Attribute `_min` und `_max` definieren den gültigen Datumsbereich. Sie greifen zuverlässig nur bei der Auswahl über den Kalenderdialog (Datepicker). Bei manueller Texteingabe kann ein Wert außerhalb des definierten Bereichs eingegeben werden, ohne dass automatisch eine Korrektur oder Fehlermeldung erfolgt. Die Validierung manueller Eingaben liegt in der Verantwortung der einbindenden Anwendung.

<InputDatePreview
	visibleProperties={['_min', '_max']}
	initialProps={{
		_label: 'Reservierungsdatum',
		_min: '2025-01-01',
		_max: '2025-12-31',
	}}
/>

#### Schrittgröße bei Zeiteingabe

Für Typ `time` kann die Schrittgröße über `_step` festgelegt werden:

<InputDatePreview
	visibleProperties={['_step']}
	initialProps={{
		_label: 'Uhrzeit',
		_type: 'time',
		_step: '15',
	}}
/>

#### Formularattribute

Standard-Formularattribute für Validierung und Interaktion:

<InputDatePreview
	visibleProperties={['_label', '_disabled', '_readOnly', '_required']}
	initialProps={{ _label: 'Datum', _required: true }}
/>

**Verfügbare Attribute:**
- `_disabled`: Deaktiviert das Eingabefeld (mit Begründung verwenden!)
- `_readOnly`: Verhindert Bearbeitung, erlaubt aber den Fokus
- `_required`: Kennzeichnet Pflichtfelder
- `_hideLabel`: Blendet das Label visuell aus (bleibt für assistive Technologien sichtbar)

#### Fehlermeldungen

Validierungsfehler oder Hinweismeldungen werden über das Attribut `_msg` ausgegeben:

<InputDatePreview
	visibleProperties={['_msg']}
	initialProps={{
		_label: 'Datum',
		_msg: 'Das eingegebene Datum liegt außerhalb des zulässigen Bereichs.',
	}}
/>

#### Events

Zur Behandlung von Events bzw. Callbacks siehe <kol-link _label="Events" _href="../concepts/events" />.

| Event    | Auslöser                                              | Value                                  |
| -------- | ----------------------------------------------------- | -------------------------------------- |
| `click`  | Eingabefeld wird angeklickt                           | -                                      |
| `focus`  | Eingabefeld wird fokussiert                           | -                                      |
| `blur`   | Eingabefeld verliert Fokus                            | -                                      |
| `input`  | Wert wird durch Eingabe oder Auswahl geändert         | Aktueller Wert in ISO8601-Format       |
| `change` | Eingabe wurde durch Fokusabzug oder Enter abgeschlos. | Aktueller Wert in ISO8601-Format       |
