## Notes

- Global rules of the application, for example for zoom levels, hyphenation or spacing, belong in the global layer of
  the theme (`global.scss` or the `GLOBAL` entry of the theme map).
- Scss is optional: the styles work just the same as plain CSS. The theme template ships an Scss structure with mixins
  that can be reduced as needed.
