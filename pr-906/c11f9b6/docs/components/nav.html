Nav

Synonyme: Navigation, Menü, Menu, Sidebar, Seitennavigation

Beschreibung: Eine Nav-Komponente ist eine Gruppe von verwandten Links oder Navigationselementen, die Nutzer:innen direkt zu bestimmten Inhalten oder externen Seiten führen. Sie ermöglicht hierarchische Navigationsstrukturen mit mehreren Ebenen und unterstützt kompakte Darstellungsmodi für platzbegrenzte Layouts.

Die Komponente gibt ein natives nav-Element mit verschachtelten Listen aus und stellt die Einträge vertikal untereinander dar. Ein Eintrag mit _href ist ein Link, ein Eintrag ohne _href eine Schaltfläche, die – sofern vorhanden – ihre Untereinträge auf- und zuklappt.

Anwendungsfälle:

  • Hauptnavigation einer Website oder Anwendung
  • Seiten-Sidebar mit Inhaltsverzeichnis
  • Nicht-lineare Navigation mit mehreren Ebenen
  • Admin-Dashboards oder Verwaltungsoberflächen mit kategorisierter Funktionalität
  • Filterverwaltung und Kategorie-Navigation in E-Commerce-Anwendungen

Beispiel​

Darstellung einer Navigation mit aktivem Eintrag und aufklappbaren Untermenüs ohne optional gesetzte Properties:

<KolNav _label="Hauptmenü" _links={[ { "_href": "#/", "_icons": "kolicon-kolibri", "_label": "1. Menüpunkt", "_active": true }, { "_icons": "kolicon-house", "_label": "2. Menüpunkt", "_children": [ { "_href": "#/1", "_icons": "kolicon-house", "_label": "2.1. Untermenüpunkt" }, { "_href": "#/2", "_icons": "kolicon-house", "_label": "2.2. Untermenüpunkt" } ] }, { "_icons": "kolicon-house", "_label": "3. Menüpunkt", "_href": "#/" }, { "_icons": "kolicon-cogwheel", "_label": "4. Menüpunkt", "_children": [ { "_href": "#/1", "_icons": "kolicon-house", "_label": "4.1. Untermenüpunkt" }, { "_href": "#/2", "_icons": "kolicon-house", "_label": "4.2. Untermenüpunkt" } ] } ]} />

Barrierefreiheit​

  • Die Navigation ist für Screenreader als Navigationsbereich (Landmark) erkennbar und wird mit der über _label gesetzten Beschriftung angesagt. So lassen sich mehrere Navigationen auf einer Seite unterscheiden.
  • Alle Einträge sind Links oder Schaltflächen und damit per Tastatur erreichbar und bedienbar. Untereinträge eines geschlossenen Untermenüs sind nicht erreichbar.
  • Einträge mit Untermenü teilen Screenreadern mit, ob ihr Untermenü geöffnet oder geschlossen ist. Visuell wird der Zustand durch ein Plus- bzw. Minus-Symbol gekennzeichnet und nicht ausschließlich über Farbe vermittelt. Beides gilt nur, solange _collapsible aktiv ist (siehe Nicht-kollabierbare Navigation).
  • Der aktive Eintrag (_active) wird visuell hervorgehoben. Als aktuelle Seite angesagt wird ein Link-Eintrag nur über den aria-current-Service (siehe Aktiver Eintrag).

Konkrete Designentscheidungen​

EntscheidungBegründung
Die Beschriftung _label ist Pflicht. Fehlt sie oder trägt eine weitere Navigation auf der Seite dieselbe Beschriftung, weist KoliBri im Entwicklungsmodus in der Konsole darauf hin.Eine Seite kann mehrere Navigationen enthalten (z. B. Haupt- und Unternavigation, Breadcrumb, Pagination). Damit Nutzende assistiver Technologien sie unterscheiden können, muss jede Navigation eindeutig beschriftet sein.
Bei mehr als sieben Einträgen auf der obersten Ebene gibt KoliBri im Entwicklungsmodus einen UI/UX-Hinweis in der Konsole aus.Innerhalb von Navigationsstrukturen wird empfohlen, nicht mehr als sieben Menüpunkte zu verwenden ().

Links und Referenzen​

Tastatursteuerung​

Die Tastaturbedienung wird durch den Browser und das Betriebssystem bestimmt. Daher können sich einzelne Tastaturfunktionen je nach Browser und Endgerät unterscheiden.

Typischerweise werden folgende Funktionen unterstützt:

TasteFunktion
TabSpringt zum nächsten Eintrag bzw. zum Kompakt-Button. Untereinträge werden nur erreicht, wenn ihr Untermenü geöffnet ist.
Shift+TabSpringt zum vorherigen Eintrag.
EnterFolgt dem fokussierten Link bzw. öffnet oder schließt das Untermenü des fokussierten Eintrags ohne _href.
SpaceÖffnet oder schließt das Untermenü des fokussierten Eintrags ohne _href bzw. betätigt den Kompakt-Button.

Pfeiltasten werden nicht unterstützt; zwischen den Einträgen wird ausschließlich mit Tab gewechselt.

FAQ​

Kann ich die Navigation horizontal darstellen?
Nein. Die Komponente stellt die Einträge vertikal dar. Die frühere Property _orientation ist in KoliBri 4 nicht mehr vorhanden.

Wie viele Ebenen werden unterstützt?
Unbegrenzt viele Ebenen sind theoretisch möglich, aber praktisch sollten es maximal 2–3 sein, um die Usability zu gewährleisten. Strukturieren Sie die Hierarchie logisch und vermeiden Sie zu tiefe Verschachtelungen – verwenden Sie stattdessen mehrere flachere Ebenen oder alternative Navigationsmuster.

Wie formuliere ich Beschriftungen und Icons?
Nutzen Sie aussagekräftige, prägnante Labels, die das Ziel oder den Inhalt klar beschreiben. Verwenden Sie Icons nur ergänzend zu Labels – nie als Ersatz. Für die kompakte Darstellung sollte jeder Eintrag ein passendes Icon über _icons erhalten: Einträge ohne Icon zeigen dort alle dasselbe Standard-Icon.

Wie kann ich die Navigationsbreite ändern?
Nutzen Sie _hasCompactButton, um einen Button unterhalb der Navigation anzuzeigen, der zwischen normaler und kompakter Darstellung (nur Icons) umschaltet – das spart insbesondere bei Navigationen mit vielen Einträgen Platz. Mit _hideLabel startet die Navigation direkt in der kompakten Darstellung, z. B. für eine kompakte Seiten-Navigation. Siehe Kompakter Modus mit Button und Kompakte Darstellung.

Wann deaktiviere ich _collapsible?
_collapsible steuert nicht, ob Untermenüs auf- und zugeklappt werden können, sondern nur, ob der Zustand angezeigt und Screenreadern mitgeteilt wird (siehe Nicht-kollabierbare Navigation). Lassen Sie _collapsible aktiv, sobald Einträge Untermenüs haben.

Funktionalitäten​

Basis-Navigation​

Einfache flache Navigation ohne Untermenüs. Die Einträge werden über _links übergeben, die Beschriftung des Navigationsbereichs über _label.

<KolNav _label="Navigation" _links={[ { "_href": "#start", "_label": "Startseite" }, { "_href": "#about", "_label": "Über uns" } ]} />

Hierarchische Navigation mit Untermenüs​

Navigation mit mehreren Ebenen durch Nutzung von _children. Ein Klick auf einen Eintrag ohne _href öffnet bzw. schließt sein Untermenü; trägt der Eintrag zusätzlich einen _on.onClick-Callback, wird dieser vorher aufgerufen. Solche Einträge lassen sich mit _disabled deaktivieren.

Wird _links neu gesetzt, gehen manuell geöffnete Untermenüs verloren: Geöffnet sind dann nur die Untermenüs auf dem Pfad zum aktiven Eintrag.

Hinweis: Ein Eintrag mit _href und _children ist ein Link: Ein Klick folgt dem Link und öffnet das Untermenü nicht, obwohl das Plus-Symbol angezeigt und das Untermenü Screenreadern als geschlossen angesagt wird. Geöffnet wird es derzeit nur über _active. Details siehe .

<KolNav _label="Navigation" _links={[ { "_href": "#start", "_icons": "kolicon-house", "_label": "Startseite" }, { "_icons": "kolicon-house", "_label": "Oberseite", "_children": [ { "_href": "#start/sub1", "_icons": "kolicon-house", "_label": "1. Unterseite" }, { "_href": "#start/sub2", "_icons": "kolicon-house", "_label": "2. Unterseite" } ] }, { "_href": "#about", "_icons": "kolicon-info", "_label": "Über uns" } ]} />

Aktiver Eintrag​

Mit _active: true wird ein Eintrag als aktiv hervorgehoben. Beim Laden sind das Untermenü des aktiven Eintrags und alle Untermenüs auf dem Pfad zu ihm geöffnet.

_active wirkt nur visuell. Damit Screenreader einen Link-Eintrag als aktuelle Seite ansagen, setzen Sie am Eintrag _ariaCurrentValue (z. B. 'page') und teilen KoliBri die aktuelle Seite über den mit. Stimmt die übergebene Location exakt mit dem _href des Eintrags überein, wird er als aktuell gekennzeichnet.

<KolNav _label="Navigation" _links={[ { "_href": "#start", "_label": "Startseite" }, { "_label": "Leistungen", "_children": [ { "_href": "#leistungen/beratung", "_label": "Beratung" }, { "_href": "#leistungen/schulung", "_label": "Schulung", "_active": true } ] }, { "_href": "#about", "_label": "Über uns" } ]} />

Kompakter Modus mit Button​

Mit _hasCompactButton erscheint unterhalb der Navigation ein Button, der zwischen voller und kompakter Darstellung umschaltet. Der Button ist mit „Navigation minimieren“ bzw. „Navigation maximieren“ beschriftet und teilt Screenreadern mit, ob die Navigation gerade erweitert ist. Das Umschalten verändert die Property _hideLabel nicht.

In der kompakten Darstellung zeigen die Einträge nur ihr Icon; Einträge ohne Icon erhalten ein Standard-Icon. Die Beschriftung erscheint bei Maus-Hover und Tastaturfokus als Tooltip und bleibt für assistive Technologien als zugänglicher Name erhalten.

<KolNav _hasCompactButton={true} _label="Navigation" _links={[ { "_href": "#/", "_icons": "kolicon-kolibri", "_label": "1. Menüpunkt", "_active": true }, { "_icons": "kolicon-house", "_label": "2. Menüpunkt", "_children": [ { "_href": "#/1", "_icons": "kolicon-house", "_label": "2.1. Untermenüpunkt" }, { "_href": "#/2", "_icons": "kolicon-house", "_label": "2.2. Untermenüpunkt" } ] }, { "_icons": "kolicon-house", "_label": "3. Menüpunkt", "_href": "#/" }, { "_icons": "kolicon-cogwheel", "_label": "4. Menüpunkt", "_children": [ { "_href": "#/1", "_icons": "kolicon-house", "_label": "4.1. Untermenüpunkt" }, { "_href": "#/2", "_icons": "kolicon-house", "_label": "4.2. Untermenüpunkt" } ] } ]} />

Kompakte Darstellung​

Mit _hideLabel startet die Navigation in der kompakten Darstellung: Die Beschriftungen der Einträge sind visuell ausgeblendet und werden nur als Tooltip bei Hover/Fokus angezeigt.

<KolNav _hideLabel={true} _label="Navigation" _links={[ { "_href": "#/", "_icons": "kolicon-kolibri", "_label": "1. Menüpunkt", "_active": true }, { "_icons": "kolicon-house", "_label": "2. Menüpunkt", "_children": [ { "_href": "#/1", "_icons": "kolicon-house", "_label": "2.1. Untermenüpunkt" }, { "_href": "#/2", "_icons": "kolicon-house", "_label": "2.2. Untermenüpunkt" } ] }, { "_icons": "kolicon-house", "_label": "3. Menüpunkt", "_href": "#/" }, { "_icons": "kolicon-cogwheel", "_label": "4. Menüpunkt", "_children": [ { "_href": "#/1", "_icons": "kolicon-house", "_label": "4.1. Untermenüpunkt" }, { "_href": "#/2", "_icons": "kolicon-house", "_label": "4.2. Untermenüpunkt" } ] } ]} />

Icons auch im erweiterten Modus​

Mit _hasIconsWhenExpanded werden die Icons der Einträge (_icons) auch in der normalen, nicht kompakten Darstellung neben den Labels angezeigt:

<KolNav _hasIconsWhenExpanded={true} _label="Navigation" _links={[ { "_href": "#/", "_icons": "kolicon-kolibri", "_label": "1. Menüpunkt", "_active": true }, { "_icons": "kolicon-house", "_label": "2. Menüpunkt", "_children": [ { "_href": "#/1", "_icons": "kolicon-house", "_label": "2.1. Untermenüpunkt" }, { "_href": "#/2", "_icons": "kolicon-house", "_label": "2.2. Untermenüpunkt" } ] }, { "_icons": "kolicon-house", "_label": "3. Menüpunkt", "_href": "#/" }, { "_icons": "kolicon-cogwheel", "_label": "4. Menüpunkt", "_children": [ { "_href": "#/1", "_icons": "kolicon-house", "_label": "4.1. Untermenüpunkt" }, { "_href": "#/2", "_icons": "kolicon-house", "_label": "4.2. Untermenüpunkt" } ] } ]} />

Nicht-kollabierbare Navigation​

Ist _collapsible deaktiviert, entfallen das Plus- bzw. Minus-Symbol an Einträgen mit Untermenü. Die Untermenüs lassen sich weiterhin per Klick öffnen und schließen.

Hinweis: Bei deaktiviertem _collapsible wird Screenreadern derzeit nicht mitgeteilt, ob ein Untermenü geöffnet oder geschlossen ist, obwohl es sich weiterhin auf- und zuklappen lässt.

<KolNav _collapsible={false} _label="Navigation" _links={[ { "_href": "#start", "_label": "Startseite" }, { "_label": "Leistungen", "_children": [ { "_href": "#leistungen/beratung", "_label": "Beratung", "_active": true }, { "_href": "#leistungen/schulung", "_label": "Schulung" } ] }, { "_label": "Kontakt", "_children": [ { "_href": "#kontakt/formular", "_label": "Kontaktformular" }, { "_href": "#kontakt/anfahrt", "_label": "Anfahrt" } ] } ]} />

Overview​

The Nav component renders a group of related links or navigation elements that perform an action or display content when clicked. It provides a highly configurable vertical or horizontal navigation bar that can represent multiple levels and vary in width.

Properties​

PropertyAttributeDescriptionTypeDefault
_collapsible_collapsibleDefines if navigation nodes can be collapsed or not. Enabled by default.boolean | undefinedtrue
_hasCompactButton_has-compact-buttonCreates a button below the navigation, that toggles _collapsible.boolean | undefinedfalse
